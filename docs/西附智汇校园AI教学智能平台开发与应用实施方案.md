## 一、项目背景与建设依据

### （一）政策背景

当前，教育数字化转型正由“数字化”迈向“智能化生态重构”的关键阶段。国家相继出台系列政策，明确要求推动人工智能与教育教学深度融合，促进教育理念、教学模式、评价方式和治理方式的系统变革。本方案主要依据以下政策文件和参考资料编制：

1. 《教育强国建设规划纲要（2024—2035年）》；
2. 《教育部办公厅关于加强中小学人工智能教育的通知》；
3. 《中小学人工智能通识教育指南（2025年版）》《中小学生成式人工智能使用指南（2025年版）》；
4. 《生成式人工智能服务管理暂行办法》；
5. 《中华人民共和国网络安全法》《中华人民共和国数据安全法》《中华人民共和国个人信息保护法》《中华人民共和国未成年人保护法》；
6. 《网络安全等级保护基本要求》（GB/T 22239—2019）；
7. 国家中小学智慧教育平台建设与应用相关要求；
8. 参考资料：《中小学教师生成式人工智能应用能力进阶研究报告》、《广东省基础教育人工智能全域场景应用指南》及其平台/工具指引。

### （二）学校基础

西南大学附属中学两江中学校（以下简称“西附两江”）地处重庆两江新区，依托西南大学附属中学教育集团的优质办学资源和西南大学的高校学术资源，在课程建设、教师发展、生涯教育和信息化应用方面具备良好基础。学校现有教学班【XX】个、教师【XX】人、学生【XX】人，已建成校园网络、智慧教室【XX】间及部分教学应用系统，为建设校级AI教学智能平台提供了基础条件。

### （三）现状与问题

1. **AI工具分散，使用门槛高。** 教师各自使用豆包、DeepSeek、Kimi等通用工具，账号分散、能力不一，缺少统一入口和学校级规范，优质用法难以复用。
2. **校本资源未形成知识资产。** 教案、试题、课件、教研成果分散在个人电脑和各类平台，缺少结构化沉淀，无法被AI有效检索和调用。
3. **经验难以沉淀共享。** 骨干教师的命题、审题、教学设计经验停留在个人层面，缺少把“个人经验”转化为“学校能力”的机制和工具。
4. **数据孤岛明显。** 教学、作业、检测、评价、管理数据分散在不同系统，缺少统一的数据底座，难以支撑精准教学和科学决策。
5. **安全与伦理风险缺少统一管控。** 生成内容的科学性审核、学生数据保护、AI使用边界等缺少学校层面的统一规范和技术手段。

### （四）建设必要性

建设“西附智汇校园”AI教学智能平台，是落实国家教育数字化战略行动、推进人工智能赋能教育教学的具体举措；是为教师减负增效、推动课堂提质升级、促进学生核心素养落地的现实需要；也是把西附两江的教学经验沉淀为可持续复用的学校数字资产、形成可向集团校和其他学校复制推广的“西附模式”的重要路径。

## 二、总体思路与建设目标

### （一）指导思想

坚持立德树人根本任务，坚持育人为本、素养为纲、伦理为先、规律为要，以“人工智能+教育”为主线，以教师专业发展和学生全面发展为核心，以数据和知识为驱动，构建“学校统一建设、教师个性使用、经验持续沉淀、能力持续扩展”的校园AI教学基础平台，推动技术赋能与教学实践深度融合，实现减负增效、提质升级、素养落地。

### （二）基本原则

| 原则 | 内涵 |
| --- | --- |
| 育人为本 | 技术服务于教学目标和学生发展，AI定位为“智慧学伴”和“辅助工具”，不替代教师的育人主体地位。 |
| 统建共享 | 学校统一建设算力、模型、知识库和公共Skill，统一标准、统一入口、统一管理，全校共享。 |
| 个性使用 | 每位教师拥有独立账号和个人AI工作空间，可结合自身教学经验创建专属Skill和个人知识库。 |
| 持续沉淀 | 建立“个人Skill—教研组Skill—学校公共Skill”的经验沉淀与晋升机制，让优秀经验持续积累。 |
| 安全可控 | 落实网络安全等级保护和未成年人数据保护要求，接入已备案大模型，生成内容“三重把关”。 |
| 开放可复制 | 采用模块化、多租户架构和标准化接口，支持后续向集团校及其他学校复制部署。 |

### （三）建设目标

#### 1. 总体目标

用1—2年时间，建成覆盖“教、学、评、管、研”全流程的“西附智汇校园”AI教学智能平台，形成“一个平台、一套知识库、一批校本Skill、一支AI种子教师队伍、一套安全伦理规范”的建设成果，打造重庆市基础教育人工智能应用示范校。

## 三、总体架构设计

### （一）总体架构

平台采用“1+1+4+N”总体架构：**1个智能算力底座**（DataThinking异构算力调度与管理平台）、**1个教育数据中心**（统一数据与知识底座）、**4大应用场域**（人工智能基础设施、人工智能赋能教与学、人工智能赋能学生全面发展、人工智能赋能教师专业发展）、**N个教学应用与Skill**。分层架构如下：

| 层级 | 主要内容 |
| --- | --- |
| 门户与终端层 | Web端（教师/学生/管理员）、移动端（“移动讲台”、学生学习端、家长端）、教室大屏与电子白板、数据驾驶舱大屏 |
| 应用层 | 教师AI工作台、AI助手、AI教学Skill中心、AI创作中心、资源中心、教学应用广场、学生自主学习、教育管理、数据驾驶舱 |
| Skill与智能体层 | 学校公共Skill、教研组Skill、教师个人Skill；学科教学智能体、苏格拉底学伴、AI助教；Skill编排与工作流引擎 |
| 模型与能力层 | 多模型网关（文本、推理、多模态）；RAG检索增强；文生图、PPT、数字人、视频、音乐、3D生成能力；OCR、语音识别与合成 |
| 数据与知识层 | 学校知识库、个人知识库与核心记忆、知识图谱（1—4级知识点）、题库、教材库、资源库、学情数据仓 |
| 算力与基础设施层 | DataThinking异构算力平台（模型仓库、资源仓库、镜像仓库、应用仓库）、私有化/混合云部署、对象存储、网络与安全设备 |
| 两大支撑体系 | 标准规范体系（数据标准、接口标准、Skill规范、内容规范）；安全保障体系（等保、内容安全、隐私保护、审计） |

### （二）用户角色与权限

| 角色 | 主要职责与权限 |
| --- | --- |
| 教师 | 个人AI工作空间、调用公共Skill、创建个人Skill、AI创作、资源管理、作业检测、学生点评、教研研修 |
| 教研组长/备课组长 | 教研组Skill与资源审核、集体备课、教研活动组织、组内数据查看 |
| 班主任 | 班级管理、学生点评、成长档案、家校沟通、班级圈 |
| 学生 | 智慧课堂、课前导学、课后作业、智能检测、AI学伴（按进阶阶段开放）、成长档案 |
| 家长 | 查看学生成长档案与学情报告、家校沟通、家长课堂 |
| 学校管理员 | 账号、知识库、Skill、模型、积分、应用数据连接、使用数据、AI治理全局管理 |
| 学校领导 | 数据驾驶舱、校级教学管理大数据、会议与文件审批 |

### （三）技术路线

1. **前端**：React + TypeScript + Tailwind CSS，组件化开发，支持深色模式和移动端自适应；对话采用流式输出（SSE/WebSocket）。
2. **后端**：微服务架构，统一API网关；业务数据采用关系型数据库，会话与缓存采用Redis，知识检索采用向量数据库。
3. **多模型网关**：统一接入已完成备案的国产大模型（如DeepSeek、通义千问、文心一言、豆包、Kimi、智谱清言等），支持按场景路由、额度控制、故障降级和用量审计。
4. **RAG知识增强**：对课标、教材、校本资源进行切片、向量化和标签化，生成内容可溯源到具体资料。
5. **身份认证**：支持统一身份认证与单点登录（SSO），可对接国家中小学智慧教育平台账号体系及学校现有系统。
6. **部署方式**：核心数据与学生数据本地化部署，模型能力采用“本地部署+云端调用”混合模式，满足数据不出校要求。
7. **多租户设计**：以“学校”为租户单元隔离数据、配置和品牌，支持复制部署到集团校及其他学校。

### （三）AI助手页面

**页面定位：** 对话式智能工作台，采用“左—中—右”三栏布局。

| 区域 | 设计要点 |
| --- | --- |
| 左侧：对话区 | 历史会话列表、新建会话、多轮对话、文件上传（Word/PDF/PPT/图片/音视频）、语音输入；模式切换：快速模式/深度思考/专业模式/专家模式 |
| 中间：工作区 | 生成结果的富文本编辑、Markdown/表格/公式渲染、思维导图与流程图预览、版本对比；一键导出Word/PDF/PPT，保存至“我的资源” |
| 右侧：状态区 | 当前调用的知识库及引用出处、Skill调用状态与执行步骤、核心记忆命中情况、所用模型及积分消耗 |

**交互要点：** 支持“@Skill”调用、“#知识库”引用；生成内容标注“AI生成，请审核后使用”；支持中断、重试和局部改写。

**验收标准：** 首字响应≤3秒；知识库引用可点击溯源；生成结果可在工作区直接编辑并导出。

### （四）AI教学Skill中心

**页面定位：** 学校教学经验的沉淀与共享中心。

| 我的Skill | 我创建的、我收藏的、我参与共建的Skill；支持版本管理与使用数据查看 |

**验收标准：** 普通教师15分钟内可完成一个Skill的创建与发布；Skill调用成功率≥99%。

## 五、平台功能体系建设内容

### （十）智能学习引擎与内容体系

1. **智能学习引擎：** 由学生标签、内容标签、学习内容推荐、学习路径规划、效果评价五部分组成，构建基于学习行为的推荐模型，让学生学有所获、沉浸专注，学习过程充满挑战但不感到挫败；定期参考历史及测评数据科学衡量学生能力，提供周期性薄弱点分析和针对性的学习策略建议。
2. **内容管理系统：** 管理知识图谱、题目内容、教材资源、教学素材。结合国家课程标准、多版本教材及考纲，构建学科内容体系；对标教材难度、考试难度、拓展难度设置分类体系，适配新学、复习、测验等教学场景；拆分1—4级知识点，算法对各级知识点掌握情况做出细致判断，辅助教师备课及学情跟踪。
3. **线下学情采集：** 对接批阅系统、答题卡扫描和第三方学习产品，实现线上线下学情数据贯通。
4. **教师端：** 课表、学情BI、学习管理、答疑工具、资源中心。
5. **学生端：** 学习产品、激励产品（积分、勋章、成长值）。

| 环节 | 教师 | 学生 |

## 六、AI赋能教学核心应用场景

围绕课前、课中、课后三大教学核心场景，平台把成熟的操作路径和提示词固化为学校公共Skill，教师填写少量参数即可调用，帮助教师在真实教学情境中快速上手，从“技术观望”走向“教学实践”。

### （一）课前：教学准备与设计

教学准备与设计是高质量课堂的逻辑起点。依托生成式人工智能，系统完成教材解析、教学设计、情境创设、问题链构建、学情研判等关键任务，推动教学设计由经验驱动走向数据支撑、由零散化走向结构化、由粗放化走向精准化。

| 场景 | 目标 | 对应公共Skill |

### （四）教学提示词工程

提示词是人机协同教学的结构化交互指令。平台在“创建Skill”向导中内置提示词设计框架，帮助教师掌握人机高效交互的基础能力。

#### 1. 提示词五大核心要素

| 要素 | 说明 |
| --- | --- |
| 角色设定（Role） | 明确智能体身份、专业背景与教学定位，引导其调用对应领域知识与表达范式 |
| 任务描述（Task） | 清晰界定教学任务目标、核心动作与预期产出，避免模糊表述 |
| 情境背景（Context） | 提供教学对象、学段、学情、课标依据、教材版本等关键背景，缩小理解偏差 |
| 输出规范（Format） | 明确内容结构、篇幅、风格、格式与呈现形式 |
| 约束条件（Constraints） | 限定内容边界、伦理规范、学段适配性、语言风格等，排除无关输出 |

**完整示例：**

```
【角色】你是深耕高中物理教学的特级教师，拥有15年教学经验，擅长情境化、探究式教学设计。
【背景】请为高一学生设计“牛顿第二定律”新授课教案。学生已学习力与运动的基本关系，
        基础差异较大，40分钟课时，配备互动白板与传感器实验器材。
【任务】设计一份完整、可直接实施的教案。
【输出】包含分层目标、教学准备、情境导入、探究活动、差异化练习、课堂评估，结构清晰。
【约束】贴合生活、分层适配、遵循认知规律、保障实验安全与全员参与。
```

#### 2. CLEAR提示词设计框架

| 原则 | 要求 |
| --- | --- |
| 简洁性（Concise） | 聚焦核心任务，剔除冗余表述，指令精炼、单一聚焦 |
| 逻辑性（Logical） | 任务步骤序列化，信息层级清晰，符合教学思维 |
| 明确性（Explicit） | 精准定义输出格式、范围、深度，术语清晰、排除项明确 |

| 反思性（Reflective） | 要求输出自检、溯源、评估，强化质量把控 |

### （五）教学智能体的开发与应用

#### 1. 苏格拉底式学伴

苏格拉底问答法通过“诘问—引导—反思”的对话范式激发自主思考，而非直接灌输知识。该类智能体围绕四大功能搭建交互体系：

1. **冲突激发：** 基于学科知识逻辑与常见认知误区设计“矛盾式提问”，引发认知冲突；
2. **自主探究：** 采用“阶梯式追问”引导学生逐步深入思考、自主推导结论；
3. **思维培养：** 通过“论证式提问”促使学生梳理逻辑链条，强化批判性思维；
4. **分层适配：** 基于学情动态调整提问难度，对基础较弱学生采用“具象化提问”，对能力较强学生采用“开放性提问”，始终处于“最近发展区”。

#### 2. 学科适配性角色定位

| 智能体角色 | 培育重点 | 典型应用 |
| --- | --- | --- |
| 数学思维教练 | 逻辑建模、推理能力 | 几何证明中连环追问定理依据与推导步骤；函数应用中引导“变量分析—模型构建—结果验证” |
| 语文深度解读伙伴 | 文本建构、审美鉴赏 | 古诗词意象解构与情感溯源；议论文“论点提炼—论据筛选—逻辑梳理”支架式提问 |
| 英语情境化语伴 | 语言运用、跨文化交际 | 模拟真实语境对话，关注语用得体性，提供替代表达与文化背景解读 |
| 科学探究设计顾问 | 实证思维、探究能力 | 引导提出假设、定义变量、设置对照组，分析误差来源与改进方案 |
| 历史思辨引导者 | 史料实证、历史解释 | 提供多元史料，引导辨析作者立场对记载客观性的影响 |

#### 3. 优化应用策略

1. **融合设计，明确分工：** 教师主导情感关怀、价值引领、活动设计与复杂决策；智能体承担知识检索、练习生成、即时反馈、过程数据记录等重复性任务。课前智能体做前置诊断，课中辅助分组探究，课后提供个性化巩固。
2. **分层应用，适配学情：** 高中阶段聚焦高阶思维与创新实践；学困生提供基础型支架，中等生提供提升型支架，优等生提供挑战型任务；遵循“启发式提问—示例引导—步骤分解”的梯度支持逻辑。
3. **过程评估，闭环优化：** 教师查看学生与智能体的对话日志，分析提问质量、推理链条和迷思概念；学生评价反馈有效性，管理员据此优化智能体配置。
4. **伦理护栏：** 落实智能体“三不边界”——不替代教师进行学业打分与综合评价、不讨论与教学无关或敏感内容、不收集学生身份敏感数据。

### （六）融合与共创：综合性学习的智能化设计

1. **单元整体教学设计：** AI辅助完成单元目标拆解、课时规划、大单元学历案与跨学科资源包生成，资源按“基础资源—提升资源—挑战资源”分层，并标注“资源类型—应用环节—使用支架—适配说明”。
2. **学科主题学习设计：** 围绕学科大概念组织主题学习，AI辅助生成主题情境与学习任务群。
3. **项目式学习设计：** AI介入“启动—规划—探究—展示—反思”全流程：

| 环节 | AI支持内容 |
| --- | --- |
| 驱动性问题 | 结合核心素养要求与学生认知规律，生成开放性、挑战性、有现实意义的驱动性问题，输出“素养目标—驱动性问题—探究方向—子任务—评价重点”对应体系 |
| 实践活动设计 | 关联高阶认知策略，设计从低阶到高阶有序递进的梯度任务 |
| 学生探究实践 | 信息检索与文献梳理、问题拆解与思路发散、数据处理与规律分析、方案生成与迭代、观点论证与逻辑完善、成果创作与可视化、过程记录与反思复盘（学生主导，AI辅助） |
| 过程性评价 | 构建“过程表现—成果质量—素养达成”多维评价体系，确定维度权重与评价工具 |
| 学习反思 | 设计“知识建构—能力发展—协作表现—问题解决—素养提升”结构化反思框架与递进式问题 |

## 九、数据治理与安全伦理保障

### （一）数据治理

1. **统一数据标准：** 制定师生基础数据、教学资源、学情数据、Skill元数据等数据标准与接口规范，建设教育数据中台，消除数据孤岛。
2. **数据分级分类：** 按公开、内部、敏感、核心四级管理；学生身份信息、成绩、心理健康等数据列为敏感及以上级别，加密存储、最小授权、访问留痕。
3. **数据本地化：** 学生个人数据和学校核心数据本地存储，向外部模型调用时进行脱敏处理，不以学生数据训练外部模型。
4. **数据全生命周期管理：** 明确采集、存储、使用、共享、归档、销毁各环节的责任与流程，定期开展数据安全风险评估与合规审计。

### （二）安全保障

| 类别 | 措施 |
| --- | --- |
| 系统与平台安全 | 按网络安全等级保护第三级要求建设；身份认证、访问控制、入侵防护、漏洞扫描、数据备份与容灾 |
| 模型与内容安全 | 仅接入已备案大模型；输入输出双向内容审核与敏感词过滤；生成内容标注“AI生成” |
| 隐私与合规 | 遵循个人信息保护和未成年人保护相关法律法规；采集学生数据须取得学生及监护人知情同意 |
| 知识产权 | 校本资源与教师原创Skill归属与署名规则明确；上传资源须符合版权规范 |
| 应急管理 | 建立分级分类安全事件应急预案，定期开展应急演练与安全培训 |

### （三）AI使用伦理规范

1. **“三重把关”：** 教师使用AI生成内容前，必须履行事实核查、价值审查、适切评估三重把关职责，严禁未经审查直接用于教学。
2. **坚守育人本质：** 在价值观引导、道德品质培育、情感关怀、心理支持等核心育人环节，教师亲自主导、全程参与，不由技术替代。
3. **智能体“三不边界”：** 不替代教师进行学业打分与综合评价，不讨论与教学无关或敏感内容，不收集学生身份敏感数据。
4. **积分与额度治理：** 通过积分额度引导合理使用，避免资源浪费；对异常调用进行预警。

### （四）学生人工智能使用进阶路径

遵循“从被动感知到主动创造，从工具使用到素养内化”的逻辑，结合学生发展水平分阶段开放平台功能。

| 阶段 | 学生角色 | 教师角色 | 实施要点 | 核心目标 |
| --- | --- | --- | --- | --- |
| 阶段一：认知感知期（示范） | 技术感知者、思维观察者 | 示范赋能者、价值传递者 | 教师在备课、授课、评价中显性化示范AI应用；结合案例解析AI的优势与局限；渗透原创性与知识产权观念 | 理解AI的工具本质，树立“合理用AI、善用AI”的初步意识 |
| 阶段二：规范体验期（引导） | 规范使用者、基础应用者 | 引导者、监督者、规则制定者 | 限定应用场景，严禁用于直接获取作业答案；落实“AI使用三原则”；设计结构化任务，把AI作为“思维拓展器” | 掌握基础应用技能，明确使用边界，形成“人机协同以自主思考为核心”的认知 |
| 阶段三：自主应用期（支持） | 自主决策者、高效应用者 | 支持服务者、监管评估者 | 学生按需自主选择工具；教师提供差异化支持；建立过程监管+结果监管“双重监管”；强化信息甄别与交叉验证 | 具备自主、规范使用AI的能力，实现技术应用与学习效能正向联动 |
| 阶段四：协同创生期（主导） | 主导创造者、协同设计者 | 方向把控者、素养引领者 | 依托AI开展复杂性、创新性任务；学生提出构想、AI提供支持；探讨AI公平性、创造性边界与社会责任 | 成为人机协同的主导者，实现知识深度建构与创造性成长 |

**AI使用三原则：** ①先自主思考再求助AI；②验证AI输出的准确性；③注明AI辅助的内容来源。

## 十二、预期成效与推广复制

### （一）预期成效

1. **教师层面：** 备课、命题、批改等事务性工作显著减负，教师精力更多投入教学设计、思维引导与育人工作；教师人工智能素养和数字化教学能力全面提升。
2. **学生层面：** 获得个性化、精准化的学习支持，学习方式由被动接受向主动探究转变，人工智能素养和核心素养协同发展。

1. **标准化部署：** 平台采用多租户架构，学校品牌、组织架构、知识库、Skill和模型配置均可独立设置，形成“标准化部署包+实施手册+培训课程”的复制方案。

3. **区域辐射：** 总结形成“西附智汇校园”建设与应用模式，通过公开课、成果展示、经验交流等方式向区域学校辐射推广。
