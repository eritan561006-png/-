## 一、总体提示词（System / Project Prompt）

```
你是一名资深的教育科技产品全栈工程师 + UI/UX 设计师，请为「西南大学附属中学两江中学」
设计并开发一套面向高中教师的校园 AI 智能工作平台——“两江中学智能教育助手”。

【项目定位】
为每一位教师提供独立账号与专属 AI 工作空间，统一接入学校知识库、公共 Skill、
主流大模型及多模态 AI 能力（文本、图片、PPT、绘图、数字人、视频、音乐、3D）。
教师既可调用学校统一建设的命题、审题、教案等 Skill，也可结合个人教学经验创建
专属 Skill 并持续沉淀；学校管理员统一管理教师账号、知识库、Skill、模型、积分
额度与使用数据。整体理念：“学校统一建设、教师个性使用、经验持续沉淀、能力持续
扩展”，并需保证架构可复制部署到其他学校（多校区/多租户能力）。

【第一版范围（MVP）】
只重点设计并实现以下 6 个核心界面，其余功能可先留出入口：
1. 登录页
2. 教师 AI 工作台（首页 / 入口聚合页）
3. AI 助手页面（对话式工作台）
4. Skill 中心
5. AI 创作中心
6. 管理员后台

【品牌与视觉基调】
- 客户：西南大学附属中学两江中学（重庆两江新区，隶属西南大学附中体系）
- 视觉气质：稳重、专业、学术感，同时体现"智能科技"感；避免低幼卡通风格
- 主色建议：西大附中校色（深蓝/藏青 + 辅助金色/红色，用于强调与勋章元素），
  中性色以浅灰白为底，保证长时间阅读舒适度；深色模式需同步设计
- Logo 与校名需在登录页与全局导航中体现（留出真实校徽占位符）
- 字体：中文正文使用无衬线字体（如 思源黑体 / PingFang / Noto Sans SC），
  数据类界面可用等宽字体呈现代码/token 用量

【技术栈建议（可按实际团队能力调整）】
- 前端：React + TypeScript + Tailwind CSS + shadcn/ui（组件库），状态管理用
  Zustand 或 Redux Toolkit，路由用 React Router / Next.js App Router
- 对话流：SSE / WebSocket 流式渲染，支持消息级重试、中断、多轮上下文
- 后端：Node.js(NestJS) 或 Python(FastAPI)，网关层统一代理多家大模型
  （如通义、DeepSeek、文心、GPT、Claude 等），支持模型路由与降级
- 数据库：PostgreSQL（业务数据）+ Redis（会话/缓存）+ 向量数据库
  （Milvus/PGVector/Weaviate，用于知识库检索 RAG）
- 对象存储：教案/PPT/图片/视频/音乐/3D 模型等生成物统一走对象存储（S3 协议）
- 鉴权：统一身份认证（支持对接学校已有 OA/教务系统 SSO），RBAC 权限模型
  （教师 / 学科组长 / 管理员 / 超级管理员）
- 多租户：Skill、知识库、积分体系需按"学校"维度隔离，便于后续向其他学校复制部署

【交互与可用性原则】
- 教师群体信息化水平参差不齐，界面需"三步以内完成核心任务"，避免专业术语堆砌
- 所有 AI 生成操作需展示进度/加载状态，长任务（视频/数字人/3D）需支持异步通知
- 核心操作需有清晰的撤销/重新生成/收藏/导出入口
- 积分/额度消耗需在生成前后清晰展示，避免教师"误用"超支
- 全站需支持响应式布局（教师常用笔记本 1440px，以及 iPad 备课场景）
- 无障碍：符合 WCAG AA 对比度要求

请先输出整体信息架构（站点地图）与组件规划，再逐页产出高保真设计与可运行代码。
```

### 1️⃣ 登录页（/login）

```
设计并实现"西南大学附属中学两江中学智能教育助手"的登录页。

【页面目标】
教师使用学校统一分配的账号登录，快速进入个人 AI 工作空间；体现学校品牌形象与
平台的科技感、信赖感。

【布局结构】
- 采用左右分栏布局（桌面端）：
  左侧 60%：视觉展示区 —— 学校 Logo + 校名"西南大学附属中学两江中学"
    + 平台名"智能教育助手" + 一句话价值主张（如"AI 赋能教学，让教研更高效"）
    + 背景可用校园插画/渐变几何图形，体现科技与人文并重
  右侧 40%：登录卡片区 —— 白色卡片，包含：
    - 平台图标 + "教师登录"标题
    - 账号输入框（工号/手机号/邮箱，placeholder："请输入工号"）
    - 密码输入框（带显示/隐藏切换）
    - "记住我" checkbox + "忘记密码"链接
    - 主要登录按钮（校色填充，全宽）
    - 备用登录方式分割线："或使用统一身份认证登录"
    - 统一身份认证/企业微信/钉钉登录按钮（图标+文字，视学校实际 SSO 情况）
    - 页脚：技术支持/版本号/备案信息占位
- 移动端：单栏居中卡片布局，Logo 缩小置顶

【交互细节】
- 输入校验：账号/密码为空时按钮禁用或点击后行内报错提示（红色文案 + icon）
- 登录失败：卡片顶部出现 toast/inline alert，如"账号或密码错误，还可尝试 4 次"
- 登录中：按钮切换为 loading 状态，禁止重复提交
- 首次登录/密码为默认密码时，登录成功后强制跳转"修改密码"引导
- 支持记住登录状态（token 持久化），过期后友好跳回登录页并提示"登录已过期"

【视觉规范】
- 主色：深蓝/藏青（校色），辅助金色用于按钮 hover 或强调线
- 卡片圆角 12-16px，柔和阴影
- 字体层级清晰：校名 24-28px 加粗，价值主张 14-16px 常规灰色
- 需支持深色模式切换（右上角图标）

请输出登录页的完整前端组件代码（含表单校验逻辑与登录 API 调用的 mock/接口定义）。
```

### 2️⃣ 教师 AI 工作台（首页）（/dashboard）

```
设计并实现教师登录后的"AI 工作台"首页，作为全平台的功能入口聚合页。

【页面目标】
让教师登录后一眼看清"我能用 AI 做什么"，并能一键直达高频功能：
AI 助手、命题、审题、教案、PPT、绘图、数字人、视频、音乐、3D。

【布局结构】
- 顶部全局导航栏：左侧 Logo+校名，中间可选搜索框（"搜索功能/Skill/历史记录"），
  右侧：积分余额徽章（如"⚡ 剩余 1,280 积分"）、消息通知、个人头像下拉
  （个人中心/账号设置/退出登录）
- 左侧固定侧边栏（可折叠）：AI 助手 / Skill 中心 / AI 创作中心 / 我的资源库 /
  管理员后台（仅管理员可见）
- 主内容区（自上而下）：
  1. 欢迎区： "早上好，张老师 👋" + 今日天气/日期 + 一句教学金句或使用小贴士
  2. 快捷入口九宫格/卡片墙（核心）：AI助手、命题、审题、教案、PPT、绘图、
     数字人、视频、音乐、3D 模型，共 10 个功能卡片，每卡含图标+名称+一句话
     描述，hover 时轻微上浮+阴影，点击进入对应功能
  3. "继续上次的工作"横向卡片列表：展示最近使用的对话/教案/PPT 草稿，
     带缩略图+更新时间+"继续编辑"按钮

     "期中试卷智能审题"），横向滚动卡片
  5. 使用数据小面板（个人维度）：本月已生成教案数/试题数/PPT数、
     积分消耗趋势小图表
- 右侧可选悬浮"AI 助手快捷唤起"按钮（全局悬浮球，点击弹出轻量对话框）

【交互细节】
- 功能卡片支持角标提示"新"/"学校推荐"

- 首次登录展示新手引导浮层（3-4 步高亮讲解核心入口）

【视觉规范】
- 采用卡片式网格布局，间距一致（16-24px），圆角 12px
- 图标风格统一（线性图标 + 校色强调色填充）
- 数据图表使用简洁的面积图/环形图，避免视觉噪音

请输出该首页的组件结构、响应式布局代码，以及卡片点击后的路由跳转逻辑。
```

### 3️⃣ AI 助手页面（/assistant）

```
设计并实现核心的"AI 助手"对话式工作台页面，是教师与 AI 交互的主战场。

【页面目标】
提供类 ChatGPT/Claude 的多轮对话体验，同时深度整合学校知识库检索与 Skill 调用，
让教师能"边聊边用工具"完成命题、审题、教案撰写等任务。

【布局结构】三栏式布局
- 左栏（约 20%，可折叠）：对话历史列表
  - 顶部"+ 新建对话"按钮
  - 按"今天/最近7天/更早"分组的历史会话列表，支持搜索、重命名、置顶、删除
  - 底部可切换"我的 Skill 快捷入口"迷你列表
- 中栏（约 55%，核心工作区）：
  - 顶部：当前对话标题（可编辑）+ 所用模型选择器（下拉，如"DeepSeek-V3 / 
    通义千问 / GPT-4o"，显示各模型积分消耗倍率）
  - 消息流区：用户消息右对齐气泡，AI 回复左对齐，支持 Markdown 渲染、代码块、
    表格、图片预览；AI 消息下方带操作条（复制/重新生成/点赞点踩/导出为文档）
  - AI 回复过程中显示流式打字效果 + "正在调用【高考命题Skill】…"等状态提示条
  - 底部输入区：多行文本框（支持 @ 呼出 Skill、/ 呼出快捷指令）、
    附件上传（教材PDF/学生作业图片等）、知识库勾选开关（"基于学校知识库回答"）、
    发送按钮；输入框上方展示已选中的 Skill/知识库 标签（可移除）
- 右栏（约 25%，可折叠）：知识库 / Skill 调用状态面板
  - Tab 1「知识库」：展示本次对话引用到的知识库文档片段（来源文件名+页码+
    相关度高亮），点击可预览原文
  - Tab 2「Skill 调用」：展示当前对话中已/可调用的 Skill 卡片列表
    （如"高中数学命题助手""作文批改助手"），每个卡片显示调用状态
    （待调用/调用中/已完成）及输出结果摘要，点击可展开查看该 Skill 的
    结构化输出（如生成的试题 JSON 预览）
  - Tab 3「本次会话用量」：本轮对话消耗的 token/积分统计

【交互细节】
- 右栏 Tab 切换需保留各自状态，不因切换而丢失
- Skill 被 AI 自动触发调用时，右栏对应卡片高亮闪烁提示，中栏消息流中插入
  一条系统提示气泡"已调用【Skill名称】，结果见右侧面板"
- 支持将当前对话一键"发送到 AI 创作中心"（如对话中生成的试题内容一键转 PPT）
- 长时间无响应需超时提示与重试按钮

【视觉规范】
- 对话气泡圆角 16px，AI气泡背景浅灰/浅蓝，用户气泡校色浅底
- 右栏卡片使用轻边框+图标区分知识库/Skill类型
- 整体保持"专业工具感"，避免过多装饰性色彩

请输出三栏布局的响应式代码（移动端右栏/左栏收起为抽屉），
以及消息流的流式渲染组件实现思路。
```

### 4️⃣ Skill 中心（/skills）

```
设计并实现"Skill 中心"页面，管理学校公共 Skill 与教师个人 Skill。

【页面目标】
让教师能便捷地"发现并使用"学校统一建设的教学 Skill（如命题、审题、教案模板），
也能"沉淀并复用"自己的教学经验为个人专属 Skill。

【布局结构】
- 顶部：页面标题"Skill 中心" + 搜索框（按名称/标签搜索）+ "创建 Skill"主按钮
- Tab 切换：「学校公共 Skill」/「我的 Skill」/（可选）「团队共享 Skill」
- 筛选栏：按学科（语文/数学/英语/物理…）、按类型（命题/审题/教案/批改/其他）、
  按排序（最多使用/最新发布）筛选
- 主体：卡片网格布局，每张 Skill 卡片包含：
  - Skill 图标/封面图 + 名称 + 一句话描述
  - 标签（学科/类型/来源：学校官方 or 教师xxx创建）
  - 使用次数/评分（如"⭐4.8 · 1.2k次使用"）
  - 操作按钮："立即使用"（跳转 AI 助手并预装该 Skill）、"查看详情"、
    （我的Skill下还有）"编辑"/"分享"/"删除"
- 「创建 Skill」流程（点击后进入引导式创建面板/弹窗）：
  1. 基本信息：名称、描述、图标、所属学科、可见范围（仅自己/学科组/申请公开）
  2. 能力定义：
     - 方式A：表单式配置（输入指令模板/提示词、输出格式、引用知识库范围）
     - 方式B：对话式创建（与 AI 对话描述需求，AI 辅助生成 Skill 配置草案）
  3. 测试运行：输入示例问题，实时预览 Skill 输出效果，可反复调整
  4. 发布：保存为"我的 Skill"，或"申请加入学校公共 Skill 库"（进入管理员审核流程）
- Skill 详情页/抽屉：展示完整说明、使用示例、版本历史、使用该 Skill 的
  其他教师评价（如启用）

【交互细节】
- 公共 Skill 与个人 Skill 视觉区分（如公共Skill带"学校认证"徽章）
- 个人 Skill 支持草稿状态（未发布）与已发布状态的标签区分
- "申请公开"后显示审核中状态，管理员审核通过/驳回后教师收到通知

【视觉规范】
- 卡片风格与工作台功能卡片呼应，但增加"作者/来源"信息条
- 官方 Skill 卡片可用校色边框或角标强化权威感

请输出 Skill 中心的列表页、创建 Skill 的多步表单组件，以及卡片交互逻辑代码。
```

### 5️⃣ AI 创作中心（/studio）

```
设计并实现"AI 创作中心"，教师在此生产多模态教学资源：图片、PPT、视频、音乐、
数字人、3D 模型。

【页面目标】
提供统一的多模态创作入口，每种创作类型有独立的参数配置与结果预览流程，
生成结果可直接沉淀进"我的资源库"并复用到教案/课件中。

【布局结构】
- 顶部：页面标题"AI 创作中心" + 顶部横向 Tab/图标导航切换 6 种创作类型：
  🖼️ 图片　📊 PPT　🎬 视频　🎵 音乐　🧑‍💻 数字人　🧊 3D模型
- 每种创作类型采用统一的"左配置 + 右预览"两栏布局：
  左栏（配置区，约35%）：
    - 输入框：描述你想要的内容（支持从 AI 助手对话一键带入文本）
    - 参数面板（按类型不同）：
      · 图片：风格选择（写实/插画/板书手绘风等）、比例、数量、参考图上传
      · PPT：主题/学科、页数、模板风格选择、是否引用知识库/教案内容
      · 视频：时长、分辨率、配音音色、字幕开关、脚本/分镜输入
      · 音乐：时长、风格（轻音乐/课间铃声/朗诵配乐）、情绪基调
      · 数字人：形象选择（预置教师形象/自定义）、播报文案、音色、背景
      · 3D模型：物体描述（如"细胞结构模型""几何体"）、输出格式（用于打印/展示）
    - 底部"生成"按钮 + 预估消耗积分提示
  右栏（预览/结果区，约65%）：
    - 生成中：进度条 + 预计剩余时间（视频/数字人/3D 为异步长任务，
      提示"生成中，完成后将通知你，可先去做其他事情"）
    - 生成完成：结果预览（图片画廊/PPT翻页预览/视频播放器/音乐波形播放条/
      数字人视频/3D模型可交互查看器），下方操作栏：下载、保存到资源库、
      重新生成、分享给同事、（PPT/图片）二次编辑
- 底部或侧边：该类型的历史生成记录横向缩略图列表，可快速复用参数再次生成

【交互细节】
- 长耗时任务（视频/数字人/3D）支持离开页面后台生成，完成后站内消息通知+
  首页"继续上次工作"卡片中出现
- 生成失败需明确错误原因（如"内容涉及敏感词，请调整描述"）与重试入口
- 积分不足时在点击生成前拦截提示，并引导联系管理员或查看积分说明

【视觉规范】
- 每种创作类型使用独立强调色小图标，整体保持统一网格与间距
- 预览区需针对不同媒体类型有恰当的空状态插画（未生成时的引导画面）
```

### 6️⃣ 管理员后台（/admin）

```
设计并实现学校管理员使用的后台管理系统，统一管理教师账号、知识库、Skill、
模型、积分与使用数据。

【页面目标】
让学校信息化管理员/教务负责人能高效地完成平台治理工作，并通过数据看板
掌握全校 AI 工具使用情况，为后续决策（如追加积分预算、推广优秀 Skill）提供依据。

【布局结构】
- 独立后台布局：顶部简洁导航（后台名称 + 返回教师端入口 + 管理员账号），
  左侧模块导航：数据看板 / 教师账号 / 知识库 / Skill 管理 / 模型管理 / 积分管理

1. 数据看板（首页，默认展示）
   - 顶部核心指标卡：活跃教师数、本月对话总数、本月内容生成数（分图片/PPT/
     视频等）、积分消耗总量，均带环比变化箭头
   - 图表区：使用趋势折线图（按日/周）、各功能模块使用占比环形图、
     各学科/年级组使用热力排行榜
   - 异常/预警提示区：积分即将超支的教师列表、长期未登录教师提醒

2. 教师账号管理
   - 教师列表表格：姓名、工号、学科、部门、账号状态（启用/禁用）、
     本月积分使用/剩余、最近登录时间
   - 批量操作：批量导入（Excel模板）、批量分配积分、批量启用/禁用
   - 单个教师详情抽屉：基本信息编辑、密码重置、角色权限调整
     （教师/学科组长/管理员）、该教师的使用记录明细

3. 知识库管理
   - 知识库列表：按学科/年级/文档类型分类（教材、教纲、历年试题、校本资料等）
   - 上传/更新文档入口（支持批量上传 PDF/Word/PPT，展示解析/向量化处理进度）
   - 权限设置：该知识库对哪些学科组/教师可见
   - 文档预览与手动分片/标签调整

4. Skill 管理
   - 「待审核」Tab：教师提交的"申请公开"Skill 列表，管理员可查看详情、
     测试运行、通过/驳回（驳回需填写原因）
   - 「已发布公共 Skill」Tab：可编辑、下架、调整排序/推荐位、查看使用统计
   - 「Skill 模板库」（可选）：平台侧提供的通用模板，管理员可一键引入并本地化

5. 模型管理
   - 已接入模型列表：模型名称、提供商、单次调用积分倍率、启用状态、
     当前调用成功率/延迟监控
   - 新增/配置模型接入（API Key、限流策略）
   - 模型路由/降级策略配置（如主模型异常时自动切备用模型）

6. 积分管理
   - 学校总积分池余额与消耗趋势
   - 积分规则配置：各功能/模型的积分消耗倍率设置
   - 教师积分分配：按学科组/个人设置月度额度，支持一键充值/清零重置
   - 消耗流水明细表（可导出）

【交互细节】
- 所有列表页支持搜索、筛选、分页、列自定义显示
- 关键操作（禁用账号、下架Skill、修改积分规则）需二次确认弹窗
- 数据看板支持按时间范围（本周/本月/本学期/自定义）切换

【视觉规范】
- 后台采用更高信息密度的表格+图表布局，区别于教师端的卡片式布局，
  但保持同一套色彩与组件语言
- 数据图表配色统一使用产品色板，避免同一图表中出现过多不相关色相

请输出管理员后台的整体布局框架、数据看板页面的图表组件实现，
以及"教师账号管理"列表页的完整表格交互代码。
```

## 六、非功能性需求清单

- **安全合规**：教师账号密码需加密存储、支持强制改密；师生数据（试题/学生作业等）
  需符合数据隐私与《生成式人工智能服务管理暂行办法》等相关合规要求；敏感内容
  过滤（命题/生成内容需防止泄题、防止生成不当内容）
- **多租户可复制**：Skill 库、知识库、积分体系、品牌主题均需按学校维度可配置，
  为"复制部署到其他学校"预留租户隔离与主题定制能力
- **可观测性**：模型调用成功率、延迟、积分消耗需可监控告警，便于管理员及时发现异常
- **性能**：对话首字响应 < 2s（流式），常规内容生成任务需有明确进度反馈
- **可扩展性**：模型网关层需支持新增模型/新增创作类型（如未来接入 AI 批改、
  智能排课等）而不影响现有架构

1. **阶段一（4-6周）**：登录页 + 教师 AI 工作台 + AI 助手页面（含知识库基础检索），

4. **阶段四**：个人 Skill 创建能力完善、使用数据深化分析、面向其他学校的多租户
   复制部署能力打磨
